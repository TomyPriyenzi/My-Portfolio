# Portfolio Personal - Tomas Priyenzi 🚀

Portfolio web interactivo y minimalista con diseño de letras grandes, paleta oscura, animaciones nativas y soporte bilingüe (ES / EN).

## ✨ Características

- **Diseño & Estilo**: Minimalismo oscuro con tipografía en escala grande (**Montserrat ExtraBold** para títulos e **Inter** para cuerpo).
- **Background**: Grid dinámico con gradiente radial y detalles en gris grafito.
- **Hero Interactivo**:
  - Animación de entrada tipo slide para nombre y apellido.
  - Indicador de ubicación con animación de latido/pulso en verde.
- **Navbar Inteligente**:
  - Se oculta al hacer scroll hacia abajo y reaparece al scrollear hacia arriba.
  - Efecto mecanógrafo (*typewriter*) cíclico alternando roles (*Desarrollador Web*, *Desarrollador Mobile*, *Diseñador UI/UX*).
  - Selector de idioma con banderas (**ES 🇦🇷 / EN 🇺🇸**).
  - Hover con subrayado animado en color violeta (`#7c3aed`).
- **Habilidades**: Secciones animadas con entradas laterales por IntersectionObserver.
- **Proyectos (Efecto Stacking)**:
  - Tarjetas que se apilan con `position: sticky` imitando el comportamiento táctil de sugerencias de Mercado Pago.
  - Bordes superior y derecho en violeta brillante (`#8b5cf6`).
- **Contacto**:
  - Mensaje destacado y sutil animación de distorsión.
  - Tipografía imponente "TOMY" de fondo.
  - Enlaces a redes sociales y correo con microinteracciones.
- **Efecto Glow Continuo**:
  - Spotlight de luz gris claro que recorre la página y revela pixel por pixel los elementos bajo el cursor con `mix-blend-mode: screen`.
- **Barra de Scroll**: Personalizada con acento violeta (`#7c3aed`).

## 🛠️ Tecnologías

- [React 19](https://react.dev/)
- [Vite](https://vitejs.dev/)
- CSS3 puro (sin frameworks pesados, 100% animaciones fluidas)

## 📦 Instalación y Uso

1. Clonar el repositorio:
```bash
git clone https://github.com/TU_USUARIO/TU_REPOSITORIO.git
cd TU_REPOSITORIO/client
```

2. Instalar dependencias:
```bash
npm install
```

3. Correr en entorno de desarrollo:
```bash
npm run dev
```

4. Compilar para producción:
```bash
npm run build
```
